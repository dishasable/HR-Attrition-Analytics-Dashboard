# HR Attrition Analytics Dashboard

## Project Overview

This project analyzes employee attrition patterns using Python, SQL, and Power BI.

The objective is to identify key drivers of employee turnover and provide actionable business insights for HR teams.

---

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- MySQL
- Power BI

---

## Project Workflow

Dataset → Python EDA → SQL Analysis → Power BI Dashboard

---

## Key Insights

- Sales department has the highest attrition rate.
- Sales Representatives show the highest turnover.
- Overtime employees are 3× more likely to leave.
- Employees aged 18–25 have the highest attrition rate.
- Lower job satisfaction increases employee turnover.
- Lower-paid employees are more likely to leave.
